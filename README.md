# nikkei-sector-flow

日経225構成銘柄を**東証33業種**で集計し、売買代金シェアの移動（資金移動）を追うツール。

- **ページ**: 前場 寄り／中盤／引け・後場 寄り／中盤／大引け の6区間で、どの業種からどの業種へ資金が動いたかを表示（スマホのホーム画面に追加可）
- **LINE**: 平日の引け後（16:00頃）に、20日平均シェア比の流入・流出上位と前場→後場の移動を配信

## 仕組み
- GitHub Actions が平日に7回 `scripts/run.py` を実行し、`docs/data/` にJSONを書き出してコミット
- 構成銘柄: 日経インデックス公式 / 33業種: JPX上場銘柄一覧（週1回更新 → `data/constituents.csv`）
- 株価・出来高: Yahoo Finance（約20分遅れ）。売買代金は5分足の (高+安+終)/3 × 出来高 で概算

## 設定
- Secrets `LINE_CHANNEL_ACCESS_TOKEN`: LINE公式アカウントのチャネルアクセストークン（未設定ならLINE送信をスキップ）
- 手動実行: Actions →「セクター資金移動の更新」→ Run workflow（日付・LINE送信の有無を指定）

| 区間 | 時間 |
|---|---|
| 前場 寄り | 9:00–9:30 |
| 前場 中盤 | 9:30–11:00 |
| 前場 引け | 11:00–11:30 |
| 後場 寄り | 12:30–13:00 |
| 後場 中盤 | 13:00–15:00 |
| 大引け | 15:00–15:30（引けの板寄せ含む） |
