# nikkei-sector-flow

日経225構成銘柄を**東証33業種**で集計し、売買代金シェアの移動（資金移動）を追うツール。

- **ページ**: 前場 寄り／中盤／引け・後場 寄り／中盤／大引け の6区間で、どの業種からどの業種へ資金が動いたかを表示（スマホのホーム画面に追加可）
- **Discord**: 平日の引け後（16:00頃）に、20日平均シェア比の流入・流出上位と前場→後場の移動を配信

## 仕組み
- GitHub Actions が平日に7回 `scripts/run.py` を実行し、`docs/data/` にJSONを書き出してコミット
- 構成銘柄: 日経インデックス公式 / 33業種: JPX上場銘柄一覧（週1回更新 → `data/constituents.csv`）
- 株価・出来高: Yahoo Finance（約20分遅れ）。売買代金は5分足の (高+安+終)/3 × 出来高 で概算

## 追加の自動処理
- **TDnet開示チェック**（`scripts/tdnet.py`）: `data/watchlist.csv` の監視銘柄の適時開示を平日8:00〜20:30の毎時:02/:07/:32/:37（15:00〜16:55は5分おき）にチェックしDiscordへ。一覧は `docs/tdnet.html`
- **マーケット速報**（`scripts/ranking.py`）: ストップ高・安、出来高・売買代金上位を11:40と15:40にDiscordへ
- **マーケット概況（日次）**（`scripts/market.py`）: 平日18:15。指数・NT倍率・日経VI・市場別売買代金・値上がり/値下がり・騰落レシオ・空売り比率・為替/金利/米国株/原油・今後1週間の予定（`data/events.json`＋SQ）
- **週次 需給レポート**（`scripts/weekly.py`）: 金曜18:30。投資部門別売買・対内証券投資・信用残・裁定残

## 設定
- Secrets `DISCORD_WEBHOOK_URL`: 通知先チャンネルのWebhook URL（未設定なら通知をスキップ）
- 任意: `DISCORD_WEBHOOK_TDNET` / `DISCORD_WEBHOOK_RANKING` / `DISCORD_WEBHOOK_MARKET` / `DISCORD_WEBHOOK_WEEKLY` を登録すると、その通知だけ別チャンネルに送る
- 手動実行: Actions →「セクター資金移動の更新」→ Run workflow（日付・通知の有無を指定）

| 区間 | 時間 |
|---|---|
| 前場 寄り | 9:00–9:30 |
| 前場 中盤 | 9:30–11:00 |
| 前場 引け | 11:00–11:30 |
| 後場 寄り | 12:30–13:00 |
| 後場 中盤 | 13:00–15:00 |
| 大引け | 15:00–15:30（引けの板寄せ含む） |
