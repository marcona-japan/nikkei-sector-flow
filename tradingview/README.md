# TradingView インジケーター「セクター資金移動（場中）」

17業種 × 代表2銘柄（計34銘柄）の売買代金（終値×出来高）から、
**直近◯分の業種シェア − 当日平均シェア（pt）** を計算して表示します。赤＝直近で資金が集まっている業種、青＝抜けている業種。

## 使い方
1. TradingViewで東証のチャート（例：日経225先物、1321、TOPIX）を 1〜15分足で開く
2. 画面下の「Pineエディタ」を開き、`sector_flow.pine` の中身を全部貼り付けて「チャートに追加」
3. 設定（歯車）で「直近の集計時間」（初期30分）、表示する業種、アラート基準（初期+3pt）を調整
4. アラート：チャート上で「アラートを作成」→ 条件にこのインジケーターを選び「alert() 関数の呼び出しのみ」

## 注意
- 東証のリアルタイムデータはTradingViewの有料データ契約が必要（未契約は約20分遅れ）
- 業種ETF（1617〜1633）は出来高が少なく資金の動きを表しにくいため、各業種の売買代金上位の大型株2銘柄で代用。銘柄は設定画面から変更可能
- 寄り付き直後は当日平均が安定しないため、9:30頃から見るのがおすすめ
